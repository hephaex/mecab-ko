## 작업 진행

### 1. 127차 보정: 형용사 기본형 NNP → VA + 다/EF

**문제**: MeCab이 "크다", "예쁘다" 같은 형용사 기본형을 NNP로 분석

**해결**:
- 26개 형용사 어간 목록 추가 (크, 작, 예쁘, 귀엽, 멋지, 아름답 등)
- `surface.ends_with("다")` + 어간 매칭으로 감지
- NNP → VA + 다/EF로 분리

**결과**:
- VA 정확도: 65.5% → **75.9%** (+10.4%) 🎉
- Token Accuracy: 78.1% → **78.9%** (+0.8%)

### 2. 128차 보정: 연결어미 EF → EC (114차 확장)

**문제**: "좋아서", "있으니까" 등 연결어미가 문장 중간에서 EF로 분석됨

**해결**:
- 114차 규칙(면서/으면서/며/으며)에 추가 패턴 포함
- 아서, 어서, 니까, 으니까, 니, 으니 추가
- 문장 중간(마지막 토큰이 아닌 경우)에서 EF → EC 변환

**결과**:
- EC 정확도: 29.9% → **32.5%** (+2.6%)
- Token Accuracy: 78.9% → **79.1%** (+0.2%)

### 3. 버그 수정: Verbose 출력 자모 정규화

**문제**: `-v` 옵션 사용 시 `ㄹ까요` vs `ᆯ까요`가 불일치로 표시됨

**원인**: verbose 비교 로직에서 자모 정규화 미적용

**해결**:
- `pred_display` 생성 시 `normalize_jamo()` 적용
- `matches` 비교 시에도 정규화 적용
