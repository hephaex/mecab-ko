## 작업 진행

### 1. 129차 보정: 일반명사 NNP → NNG

**문제**: MeCab이 "인공지능", "머신러닝" 같은 일반명사를 NNP(고유명사)로 분석

**해결**:
- 15개 기술 용어 목록 추가
- `token.pos == "NNP"` && 목록에 포함된 경우 NNG로 변환

```rust
let common_nouns: HashSet<&str> = [
    "인공지능", "머신러닝", "딥러닝", "빅데이터", "클라우드",
    "인터넷", "컴퓨터", "소프트웨어", "하드웨어", "프로그램",
    "알고리즘", "데이터베이스", "네트워크", "서버", "클라이언트",
].into_iter().collect();
```

**결과**:
- NNG 정확도: 70.3% → **71.1%** (+0.8%)
- Token Accuracy: 79.1% → **79.2%** (+0.1%)
- Sentence Accuracy: 39.7% → **40.7%** (+1.0%)

## 오류 분석 (후처리 한계)

### MeCab 사전 수준 문제 (해결 어려움)
1. **토큰 경계 오류**: `만나서` → `만나 어 서영`
2. **복합어 분리**: `특별시` vs `특별+시청`
3. **불규칙 활용**: `가겠다` → `갈+겠+다`
4. **띄어쓰기 무시**: `뭐 하니` → `뭐하니/NNP`
5. **동형이의어**: `간` (VV+ETM vs NNG "liver")
6. **줄임말**: `재미있다` → `재밌다`

### 문맥 의존적 문제
- `하/XSV` vs `하/VV`: 파생동사 vs 단독동사
- `있/VA` vs `있/VV`: 문맥에 따른 품사 차이
