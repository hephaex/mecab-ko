## 기술적 변경 사항

### 추가된 보정 규칙 (104차-110차)

#### 104차: 보조동사 VV → VX 변환
```rust
// VV + 어/아/EC + 보조동사VV → VV + EC + VX
// "추천해 준" = VV + 어/EC + 주/VX
let auxiliary_verbs = ["주", "보", "버리", "내", "두", "놓", "오", "가", ...];
```

#### 105차: 진행형 있/VX
```rust
// "고/EC + 있/VV" → "고/EC + 있/VX"
// "하고 있다" = VV + 고/EC + 있/VX
```

#### 106차: 부정 않/VX
```rust
// "지/EC + 않/VV" → "지/EC + 않/VX"
// "하지 않다" = 지/EC + 않/VX
```

#### 107차: 희망 싶/VX
```rust
// "고/EC + 싶/VV" → "고/EC + 싶/VX"
// "보고 싶다" = 고/EC + 싶/VX
```

#### 108차: 인용형 연결어미 병합
```rust
// "자/EF + 고/EC" → "자고/EC" (청유형 인용)
// "다/EF + 고/EC" → "다고/EC" (평서형 인용)
// "라/EF + 고/EC" → "라고/EC" (명령형 인용)
```

#### 109차: ㄹ까/EF → EC
```rust
// "ㄹ까/EF + 하/VV" → "ㄹ까/EC"
// "갈까 하다" = 가/VV ㄹ까/EC 하/VV 다/EF
```

#### 110차: 게/NNB → EC
```rust
// VV/VA 뒤의 "게/NNB"는 EC
// "오게" = 오/VV 게/EC
```
