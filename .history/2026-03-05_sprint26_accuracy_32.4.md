## 세션 개요

## 완료한 작업

### VX (보조용언) 분리 규칙 추가
- **문제**: VX+EF가 분리되지 않음 ("있어요" → "있어요/VX")
- **해결**: `VX+EF`, `VX+EC` EndingRule 추가
- **결과**: VX 정확도 8.6% → 20.0% (+11.4%p)

추가된 코드 (sejong.rs):
```rust
// VX (보조용언) + 종결어미 (EF)
self.ending_rules.push(EndingRule::new(
    "VX+EF",
    vec![
        "습니다", "ㅂ니다", "습니까", "ㅂ니까",
        "어요", "아요", "요", "어", "아", "다",
        "ㄴ다", "ㅆ다", "지", "죠", "네",
    ],
    vec!["VX", "EF"],
));

// VX + 연결어미 (EC)
self.ending_rules.push(EndingRule::new(
    "VX+EC",
    vec![
        "고", "면", "으면", "서", "어서", "아서",
        "면서", "으면서", "니까", "으니까", "지만",
    ],
    vec!["VX", "EC"],
));
```

### 사용자 사전 확장
1. **축약형 과거시제** VV+EF로 변경 (갔다, 왔다, 했다, 봤다)
   - 정답 데이터 형식 맞춤: "갔/VV 다/EF"
2. **형용사 기본형 추가** (낮다, 높다, 길다, 짧다 등)
3. **복합 형용사 추가** (-5000 비용으로 우선 적용)
   - 재미있다, 재미없다, 맛있다, 맛없다
4. **복합명사 추가** (한국어, 자연어, 형태소, 분석기, 연구소 등)
5. **대명사 목적격 패턴 추가** (그를, 그녀를, 우리를 등)

## 발견된 이슈

### 1. verbose 출력 불일치
- CLI 직접 테스트와 evaluate verbose 출력이 다름
- "한국어"가 CLI에서는 NNG로 분석되지만 verbose에서는 "한국/NNP 어/NNG"로 표시
- 원인 조사 필요

### 2. 정답 데이터 불일치
- 동사 나열 문장 ("가다 갔다 가겠다")에서 "갔다/VV"처럼 단일 토큰으로 태그
- 일반 문장에서는 "갔/VV 다/EF"로 분리
- 일관성 없는 정답 데이터로 인한 정확도 한계

### 3. XSV/EP 정확도 정체
- XSV: 9.4% (개선 안 됨)
- EP: 13.8% (개선 안 됨)
- 세종 변환에서 VV+EP+EF 분리 규칙이 있지만 적용되지 않는 케이스 존재
