# Sprint 33 - NNB 정확도 개선 세션

**날짜**: 2026-03-10
**목표**: 60% 정확도 달성 (현재 59.7%)

## 세션 개요

PM Auto Mode 진행 중. NNB(의존명사) 정확도를 개선하기 위한 71차-74차 보정 규칙 추가.

## 변경 사항

### 1. 71차 보정: 의존명사 "중" 처리
- "계류 중이다", "분석 중이다" 패턴에서 "중/NNG + 이/VCP" → "중/NNB + 이/VCP"
- NNG/NNP 뒤에 "중"이 오고 VCP/JX/JKS/EF가 따라오면 NNB로 변환

### 2. 72차 보정: ETM 뒤의 "지" 의존명사
- "만난 지", "먹은 지" 패턴에서 ETM + "지/VX" → ETM + "지/NNB"
- ETM(관형형 전성어미) 뒤에 오는 "지"는 시간 경과를 나타내는 의존명사

### 3. 73차 보정: "것" 의존명사 처리
- "것/NP" → "것/NNB" (VCP, JKS, JX, JKO 앞 또는 ETM 뒤)
- 대명사로 분석되던 "것"을 의존명사로 변환

### 4. 74차 보정: 관형형 VV 분리
- "간/온/한/갈/올/할" + 명사 패턴
- 예: "간 사람" → "가/VV ㄴ/ETM 사람/NNG"
- 예: "할 일" → "하/VV ㄹ/ETM 일/NNG"
