# Sprint 26 정확도 개선 작업 세션 로그 (계속)

## 날짜: 2026-03-05

## 세션 개요
Sprint 26의 정확도 35% 목표를 향한 개선 작업 계속. 32.4% → 34.2%로 향상.

## 완료한 작업

### 1. NP+JKB 분리 규칙 추가
- **문제**: "나에게"가 NP로만 분석되고 JKB가 분리되지 않음
- **해결**: tag_map과 EndingRule에 NP+JKB 추가
- **결과**: NP 정확도 57.7% → 65.4% (+7.7%p)

### 2. EC 연결어미 패턴 순서 재정렬
- **문제**: "만나서"가 "만나/VV 아서/EC"가 아닌 "만나/VV 서/EC"로 분리됨
- **원인**: "서"가 "아서"보다 먼저 매칭됨
- **해결**: 긴 패턴을 먼저 배치 (아서 > 서)
- **결과**: EC 정확도 23.9% → 27.4% (+3.5%p)

### 3. 복합명사 비용 최적화
- **문제**: "한국어 형태소"에서 "한국어"가 "한국/NNP 어/NNG"로 분리됨
- **해결**: 복합명사 비용 -500 → -5000 → -10000
- **결과**: NNG 정확도 46.5% → 49.9% (+3.4%p)

### 4. NNG+JKB (와/과) 패턴 추가
- **문제**: "친구와"가 "친구/NNG 와/IC"로 분석됨
- **해결**: NNG+JKB 비용 -15000으로 설정
- **결과**: JKB 정확도 34.9% → 39.5% (+4.6%p)

### 5. 기본 명사 사전 확장
- 친구, 영화, 산책, 연필, 준비, 회의, 어제 등 추가
- 비용 -10000으로 분리 방지

## 발견된 한계점

### 1. 공백 연접 문제 (Critical)
- **증상**: "주가가 급등" → "주가 가급 등"으로 분석
- **원인**: MeCab이 공백을 무시하고 "가"(JKS)와 "급"을 연접하여 "가급"(NNG)으로 분석
- **영향**: JKS 정확도 21.2%로 제한
- **해결 필요**: SpacePenalty 재활성화 또는 word boundary 처리 개선

### 2. 축약형 과거 시제 분리 불가
- **증상**: "했어요"를 "하/VV 았/EP 어요/EF"로 분리 불가
- **원인**: "했어요"가 "었어요"로 끝나지 않음 (축약형)
- **현재 동작**: VV+EP+EF로 태그되지만 세종 변환에서 분리 안 됨

### 3. 정답 데이터 특수 형식
- "가다 갔다 가겠다" → 정답이 "가다/VV 갔다/VV 가겠다/VV"
- 동사 나열 문장에서 분리 없이 단일 토큰으로 태그
