# MeCab-Ko 사전 기여 가이드

이 문서는 mecab-ko 사전에 새로운 단어를 추가하는 방법을 설명합니다.

## 기여 방법

### 1. GitHub Issue를 통한 단어 제안 (권장)

가장 쉬운 방법은 GitHub Issue를 통해 단어를 제안하는 것입니다.

#### 단일 단어 제안

1. [New Word Request](https://github.com/hephaex/mecab-ko/issues/new?template=new-word.yml) 템플릿 사용
2. 다음 정보를 입력:
   - **단어**: 추가할 단어 (예: 메타버스)
   - **품사**: 품사 태그 선택 (아래 품사 가이드 참조)
   - **사용 예시**: 단어가 사용된 문장 2-3개
   - **출처**: 뉴스 기사, SNS 등 발견한 곳

#### 대량 단어 제안 (10개 이상)

1. [Bulk Word Candidates](https://github.com/hephaex/mecab-ko/issues/new?template=bulk-word-candidates.yml) 템플릿 사용
2. 표 형식으로 단어 목록 작성

### 2. Pull Request를 통한 직접 기여

개발에 익숙하다면 직접 CSV 파일을 수정할 수 있습니다.

```bash
# 1. 저장소 Fork 및 Clone
git clone https://github.com/YOUR_USERNAME/mecab-ko.git
cd mecab-ko

# 2. 브랜치 생성
git checkout -b feat/add-neologisms-2024

# 3. 사전 파일 수정
vim data/user-dict/neologisms.csv

# 4. 검증
./rust/target/release/mecab-ko -u data/user-dict/neologisms.csv "테스트 문장"

# 5. Commit 및 PR 생성
git add data/user-dict/neologisms.csv
git commit -m "feat(dict): add 신조어들"
git push origin feat/add-neologisms-2024
```

### 3. CLI를 통한 자동 수집

mecab-ko CLI를 사용하여 텍스트에서 미등록어를 자동으로 수집할 수 있습니다.

```bash
# 텍스트 파일에서 미등록어 수집
mecab-ko collect-unknown \
  -i articles.txt \
  -o unknown_words.csv \
  --min-freq 3 \
  --with-examples \
  --format csv

# 결과를 Issue로 제출
```

## CSV 형식 가이드

### 기본 형식

```csv
표면형,좌ID,우ID,비용,품사,분류,종류,활용형,조합읽기,원형,읽기,타입
```

### 간단 형식 (권장)

자동 설정을 사용하면 최소한의 정보만 입력해도 됩니다:

```csv
메타버스,0,0,0,NNG,*,*,*,*,메타버스,메타버스,*
챗GPT,0,0,0,NNP,*,*,*,*,챗지피티,챗지피티,*
```

| 필드 | 값 | 설명 |
|------|-----|------|
| 표면형 | 실제 단어 | 반드시 입력 |
| 좌ID | 0 | 자동 설정 |
| 우ID | 0 | 자동 설정 |
| 비용 | 0 | 기본 우선순위 |
| 품사 | NNG/NNP 등 | 반드시 입력 |
| 분류~종류 | * | 기본값 |
| 조합읽기 | * | 기본값 |
| 원형 | 단어 | 표면형과 동일 |
| 읽기 | 발음 | 외래어는 한글 발음 |
| 타입 | * | 기본값 |

## 품사 태그 가이드

### 명사 (N)

| 태그 | 이름 | 예시 | 사용 시점 |
|------|------|------|----------|
| **NNG** | 일반명사 | 메타버스, 워라밸, 인플루언서 | 일반적인 개념, 사물 |
| **NNP** | 고유명사 | 챗GPT, BTS, 삼성전자 | 특정 브랜드, 인물, 서비스명 |
| **NNB** | 의존명사 | 것, 수, 줄 | 혼자 쓰이지 않는 명사 |

### 용언 (V)

| 태그 | 이름 | 예시 | 사용 시점 |
|------|------|------|----------|
| **VV** | 동사 | 구독하다, 팔로우하다 | 행위, 동작 |
| **VA** | 형용사 | 힙하다, 쿨하다 | 상태, 성질 |

### 수식언

| 태그 | 이름 | 예시 | 사용 시점 |
|------|------|------|----------|
| **MAG** | 일반부사 | 매우, 정말 | 다른 말 꾸밈 |
| **MM** | 관형사 | 이, 그, 저 | 명사 앞에서 꾸밈 |

### 기타

| 태그 | 이름 | 예시 | 사용 시점 |
|------|------|------|----------|
| **IC** | 감탄사 | ㅋㅋㅋ, ㅎㅎ, 앗 | 감탄, 반응 |
| **SL** | 외국어 | AI, GPT | 영어 약어 |
| **SH** | 한자 | 株式, 會社 | 한자어 |
| **SN** | 숫자 | 123, 2024 | 숫자 |

### 품사 판단 팁

- **브랜드/서비스명** → NNP (고유명사)
- **일반적 개념/현상** → NNG (일반명사)
- **영어 약어** → SL 또는 NNP
- **~하다가 붙을 수 있으면** → NNG (예: 코딩 → 코딩하다)
- **특정 인물/그룹명** → NNP

## 품질 기준

### 필수 조건

- [ ] 실제로 사용되는 단어인가?
- [ ] 올바른 품사 태그인가?
- [ ] 기존 사전에 없는 단어인가?
- [ ] 부적절한 내용이 아닌가?

### 권장 조건

- [ ] 읽기 정보가 정확한가? (특히 외래어)
- [ ] 사용 빈도가 충분한가?
- [ ] 일시적 유행어가 아닌가?

### 검증 방법

```bash
# 1. 기존 사전 확인
mecab-ko "단어"

# 결과가 여러 토큰으로 분리되면 → 미등록어
# 결과가 한 토큰이면 → 이미 등록됨

# 2. 사용자 사전 적용 테스트
mecab-ko -u data/user-dict/neologisms.csv "단어"
```

## 비용(Cost) 설정

비용은 동음이의어 처리에 중요합니다. **낮을수록 우선순위가 높습니다.**

| 비용 | 의미 | 예시 |
|------|------|------|
| -1000 | 매우 높은 우선순위 | 자주 쓰이는 고유명사 |
| 0 | 기본값 | 일반 단어 |
| 1000 | 낮은 우선순위 | 드물게 쓰이는 전문용어 |

```csv
# 높은 우선순위 (자주 쓰임)
삼성전자,0,0,-1000,NNP,*,*,*,*,삼성전자,삼성전자,*

# 기본 우선순위
메타버스,0,0,0,NNG,*,*,*,*,메타버스,메타버스,*

# 낮은 우선순위 (전문용어)
리튬인산철,0,0,1000,NNG,*,*,*,*,리튬인산철,리튬인산철,*
```

## 자동 수집 시스템

### 주간 자동 수집

매주 월요일에 GitHub Actions가 다음 소스에서 신조어를 수집합니다:

1. **국립국어원 우리말샘 API**: 공식 신조어 사전
2. **Baram 시맨틱 검색**: 내부 지식베이스
3. **코퍼스 분석**: 텍스트에서 미등록어 추출

수집된 후보는 Issue로 생성되어 검토를 기다립니다.

### 수동 수집 실행

```bash
# GitHub Actions에서 수동 실행
# Actions → Multi-Source Neologism Sync → Run workflow
```
