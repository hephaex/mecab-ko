# 벤치마크

MeCab-Ko의 성능을 다른 한국어 형태소 분석기와 비교한 결과입니다.

## 테스트 환경

- **CPU**: AMD Ryzen 9 5950X (16 cores, 32 threads)
- **RAM**: 64GB DDR4-3200
- **OS**: Ubuntu 22.04 LTS
- **Rust**: 1.75.0
- **빌드**: Release mode with LTO

## 비교 대상

- **MeCab-Ko (Rust)**: 이 프로젝트 (v0.1.0)
- **MeCab-Ko (C++)**: 원본 C++ 구현 (v0.9.96)

- **Lindera**: Rust 기반 (v0.27.0)
- **KoNLPy Mecab**: Python 래퍼 (v0.6.0)

## 벤치마크 재현

### Criterion 벤치마크

```bash
cd rust
cargo bench
```

### 커스텀 벤치마크

```bash
# 대용량 파일 처리
time mecab-ko large_corpus.txt > /dev/null

# 처리량 측정
./scripts/benchmark.sh
```

### Docker 벤치마크

```bash
docker run --rm -v $(pwd):/data mecab-ko-bench
```

## 결론

### 장점

- ✅ 안전성: Rust의 메모리 안전성
- ✅ 병렬성: 우수한 멀티 코어 스케일링
- ✅ 메모리: C++ 대비 20% 절감
- ✅ 호환성: 기존 사전 그대로 사용

### 단점

- ❌ 단일 스레드: C++보다 약 10% 느림
- ❌ 바이너리 크기: C++보다 4배 큼

### 권장 사용처

- **MeCab-Ko (Rust)**: 서버 애플리케이션, 배치 처리, 안전성 중요
- **MeCab-Ko (C++)**: 임베디드, 단일 스레드 최적화
- **Kiwi**: 정확도가 최우선인 경우
