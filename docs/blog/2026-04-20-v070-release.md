# mecab-ko v0.7.0: 77% Memory Reduction with 100% Accuracy

**날짜**: 2026-04-20
**버전**: v0.7.0

## 요약

mecab-ko v0.7.0을 릴리스합니다. 이번 릴리스의 핵심은 **LazyEntries 로딩**으로 런타임 메모리를 150MB에서 34MB로 줄이면서도 1,100개 문장 기준 100% 토큰 정확도를 유지한 것입니다. 5개 플랫폼 사전 빌드 바이너리, 검색엔진 플러그인(ES 8.x / OS 3.x), 사전 파이프라인 자동화가 함께 포함됩니다.

## LazyEntries: 기술 심층 분석

### 문제

기존 Eager 로딩 방식은 프로세스 시작 시 전체 사전(entries.bin)을 메모리에 적재합니다. 한국어 형태소 사전은 항목 수가 많아 이 비용이 ~150MB에 달했습니다. 배치 처리나 마이크로서비스 환경에서는 불필요한 부담이었습니다.

### 설계

LazyEntries는 사전 항목을 두 계층으로 분리합니다.

```
entries.bin (v2, MKE2 포맷)
├── Header (오프셋 인덱스)  ← 시작 시 전체 로드
└── Entry blocks           ← 접근 시점에 로드
```

시작 시에는 오프셋 인덱스만 읽습니다. 개별 항목은 처음 조회될 때 디스크에서 읽어 LRU 캐시(기본 10,000 항목)에 보관합니다. 이후 동일 항목 조회는 캐시에서 서비스됩니다.

`Arc<DictEntry>` 반환 타입은 캐시에서 꺼낸 항목을 추가 복사 없이 호출자에게 공유합니다. Lazy 모드에서 디스크 I/O가 실패할 수 있으므로 반환 타입이 `Option<&DictEntry>`에서 `Result<Arc<DictEntry>>`로 바뀌었습니다.

### 실측 결과

| 지표 | Eager (v1) | Lazy (v2) |
|------|------------|-----------|
| 초기화 시간 | 806 ms | 41 ms |
| 런타임 메모리 | 291 MB | 66 MB |
| 10K 조회 시간 | 3.7 ms | 22 ms (콜드) / ~3.7 ms (웜) |

콜드 캐시 조회는 Eager 대비 느리지만, 워밍업 후에는 동등한 속도입니다. 일반적인 한국어 텍스트 처리에서는 상위 N개 항목이 반복 등장하므로 캐시 효율이 높습니다.

### v2 포맷 변환

Lazy 모드의 전체 혜택은 entries.bin이 v2 (MKE2) 포맷이어야 합니다.

```bash
# 포맷 확인
mecab-ko-dict-builder info --dict /path/to/dict

# v2 변환 (기존 파일 자동 백업)
mecab-ko-dict-builder convert --dict /path/to/dict --verbose
```

v1 (MKED) 포맷에서는 Lazy 모드가 자동으로 Eager 폴백됩니다. 하위 호환성은 유지되지만 메모리 절감 효과는 없습니다.

## 사전 파이프라인

세 가지 도메인 사전이 추가되었습니다.

- **IT 용어** (283K 항목): 기술 문서 정확도 향상
- **뉴스 NNP** (주간 자동 갱신): 인명·기관명 최신 유지, CI 검증 게이트 포함
- **관보 기관명** (503 항목): 정부 기관 공식 명칭 (cost=-5000)

뉴스 NNP 파이프라인은 CI에 정확도 게이트가 통합되어 있어 사전 업데이트가 기존 정확도를 저하시키면 자동으로 차단됩니다.

## v0.6.0에서 마이그레이션

### 빠른 시작 (Cargo.toml)

```toml
[dependencies]
mecab-ko = "0.7"
```

### API 변경 체크리스트

```rust
// 1. get_entry(): Option<&DictEntry> → Result<Arc<DictEntry>>
// v0.6.x
if let Some(entry) = dict.get_entry(index) { ... }

// v0.7.0
if let Ok(entry) = dict.get_entry(index) { ... }

// 2. entries() 제거 → entry_count()
// v0.6.x
let count = dict.entries().len();

// v0.7.0
let count = dict.entry_count();

// 3. common_prefix_search(): Vec → Result<Vec>
// v0.7.0
for (entry, len) in dict.common_prefix_search("한국어")? { ... }
```

### Eager 모드 유지 (v0.6.x 동작)

```rust
use mecab_ko_dict::dictionary::{LoadOptions, SystemDictionary};

let dict = SystemDictionary::load_with_options(
    "/path/to/dict",
    LoadOptions::speed_optimized(), // 또는 LoadOptions::eager()
)?;
```
