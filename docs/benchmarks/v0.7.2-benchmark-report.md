## 분석

### 주요 개선
1. **normalization_toggle/disabled -11.7%**: 정규화 비활성 경로에서 per-call 할당 제거 효과가 크게 나타남
2. **tokenizer_scalability/1000chars -3.3%**: 긴 텍스트에서 corrections/ 모듈의 정적 할당이 누적 효과
3. **tokenizer_wakati -1.8%**: 분석 경로 전반의 미세한 개선 누적

### 변화 없음 (예상대로)
- unicode, case, whitespace, numbers, punctuation: 정규화 경로는 corrections/ 최적화와 무관
- tokenizer basic/short: 짧은 텍스트에서는 corrections 호출 횟수 적어 효과 미미

### 주의사항
- mini-dict 사용으로 실제 분석 깊이가 제한됨
- 시스템 사전 사용 시 corrections/ 패스가 더 많이 호출되어 효과가 더 클 수 있음
- ±2% 이내 변화는 측정 노이즈로 간주
