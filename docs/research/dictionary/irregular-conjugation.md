## 1. 개요

한국어 용언(동사/형용사)의 불규칙 활용 패턴을 정리합니다.
mecab-ko-dic의 Inflect.csv에는 이미 확장된 활용형이 저장되어 있으며,
12번째 컬럼에 원형 분해 정보가 포함되어 있습니다.

### mecab-ko-dic 형식
```
표면형,좌ID,우ID,비용,품사,*,받침,원형,Inflect,원품사,끝품사,분해결과
가까와,1804,3,1684,VA+EC,*,F,가까와,Inflect,VA,EC,가깝/VA/*+아/EC/*
```

## 2. ㅂ불규칙

### 특징
- 어간 받침 `ㅂ`이 모음 앞에서 `오/우`로 변함
- 형용사에서 주로 발생

### 변환 규칙
```
어간 + 아/어 → 어간(-ㅂ) + 와/워
가깝 + 아 → 가까와
춥 + 어 → 추워
덥 + 어 → 더워
```

### 주요 어휘
| 원형 | 활용형 | 분해 |
|------|--------|------|
| 가깝다 | 가까워 | 가깝/VA + 어/EC |
| 춥다 | 추워 | 춥/VA + 어/EC |
| 덥다 | 더워 | 덥/VA + 어/EC |
| 무겁다 | 무거워 | 무겁/VA + 어/EC |
| 가볍다 | 가벼워 | 가볍/VA + 어/EC |
| 어렵다 | 어려워 | 어렵/VA + 어/EC |
| 쉽다 | 쉬워 | 쉽/VA + 어/EC |
| 맵다 | 매워 | 맵/VA + 어/EC |
| 아름답다 | 아름다워 | 아름답/VA + 어/EC |
| 부럽다 | 부러워 | 부럽/VA + 어/EC |
| 밉다 | 미워 | 밉/VA + 어/EC |
| 곱다 | 고와 | 곱/VA + 아/EC |
| 줍다 | 주워 | 줍/VV + 어/EC |
| 굽다 | 구워 | 굽/VV + 어/EC |
| 눕다 | 누워 | 눕/VV + 어/EC |

### 예외 (ㅂ규칙)
```
좁다 + 아 → 좁아 (규칙)
입다 + 어 → 입어 (규칙)
잡다 + 아 → 잡아 (규칙)
```

## 3. ㄷ불규칙

### 특징
- 어간 받침 `ㄷ`이 모음 앞에서 `ㄹ`로 변함
- 동사에서 주로 발생

### 변환 규칙
```
어간(ㄷ) + 아/어 → 어간(ㄹ) + 아/어
듣 + 어 → 들어
걷 + 어 → 걸어
```

### 주요 어휘
| 원형 | 활용형 | 분해 |
|------|--------|------|
| 듣다 | 들어 | 듣/VV + 어/EC |
| 걷다 | 걸어 | 걷/VV + 어/EC |
| 묻다 | 물어 | 묻/VV + 어/EC |
| 싣다 | 실어 | 싣/VV + 어/EC |
| 깨닫다 | 깨달아 | 깨닫/VV + 아/EC |

### 예외 (ㄷ규칙)
```
받다 + 아 → 받아 (규칙)
믿다 + 어 → 믿어 (규칙)
닫다 + 아 → 닫아 (규칙)
```

## 7. ㄹ불규칙

### 특징
- 어간 받침 `ㄹ`이 ㄴ, ㅂ, ㅅ 앞에서 탈락
- 동사/형용사 모두 발생

### 변환 규칙
```
어간(ㄹ) + ㄴ → 어간(-ㄹ) + ㄴ
어간(ㄹ) + ㅂ → 어간(-ㄹ) + ㅂ
어간(ㄹ) + ㅅ → 어간(-ㄹ) + ㅅ
```

### 주요 어휘
| 원형 | 활용형 | 분해 |
|------|--------|------|
| 살다 | 사는 | 살/VV + 는/ETM |
| 알다 | 아는 | 알/VV + 는/ETM |
| 놀다 | 노는 | 놀/VV + 는/ETM |
| 팔다 | 파는 | 팔/VV + 는/ETM |
| 걸다 | 거는 | 걸/VV + 는/ETM |
| 열다 | 여는 | 열/VV + 는/ETM |
| 울다 | 우는 | 울/VV + 는/ETM |

## 8. 여불규칙 (하다 활용)

### 특징
- `하다`가 `여`로 변함
- `하다` 계열 동사/형용사에서 발생

### 변환 규칙
```
하 + 아 → 해 (하 + 여 → 해)
```

### 주요 어휘
| 원형 | 활용형 | 분해 |
|------|--------|------|
| 하다 | 해 | 하/VV + 여/EC |
| 공부하다 | 공부해 | 공부하/VV + 여/EC |
| 착하다 | 착해 | 착하/VA + 여/EC |
| 깨끗하다 | 깨끗해 | 깨끗하/VA + 여/EC |

## 9. mecab-ko-dic에서의 활용

### 분해 컬럼 형식
```
stem/POS/*+ending/POS/*
```

### 예시
| 표면형 | 분해 컬럼 |
|--------|----------|
| 가까워 | 가깝/VA/*+어/EC/* |
| 들어 | 듣/VV/*+어/EC/* |
| 지어 | 짓/VV/*+어/EC/* |
| 몰라 | 모르/VV/*+아/EC/* |
| 써 | 쓰/VV/*+어/EC/* |
| 해 | 하/VV/*+여/EC/* |

### SejongConverter에서의 처리
1. `extract_decomposition()`: features 문자열에서 분해 컬럼 추출
2. `parse_decomposition()`: 분해 컬럼 파싱
3. `convert_token()`: 분해 정보 우선 사용
