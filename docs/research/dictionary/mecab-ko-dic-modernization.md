## 2. 신조어 추가 방안

### 2.1 사용자 사전 활용 (단기)

현재 구현된 사용자 사전 기능 활용:

```rust
let mut user_dict = UserDictionary::new();
user_dict.add_entry("아이오아이", "NNP,*,*,*,*,*,*,*");
user_dict.add_entry("챗GPT", "NNP,*,*,*,*,*,*,*");
```

**장점:**
- 즉시 적용 가능
- 사용자 맞춤 가능

**단점:**
- 수동 관리 필요
- 분산된 사전 관리

## 3. 기술적 접근 방안
