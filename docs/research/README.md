# Research - 기술 조사 결과

구현 착수 전 수행하는 기술 조사 결과를 카테고리별로 저장합니다.

## 카테고리

- `algorithms/` - Viterbi, DA Trie, CRF 등 알고리즘
- `ecosystem/` - 한국어 NLP 생태계 (Kiwi, Nori, Lindera 등)
- `rust-crates/` - 활용 가능한 Rust 크레이트 조사
- `dictionary/` - 사전 포맷, 빌드 방식, 데이터 소스
- `benchmarks/` - 성능 비교, 벤치마크 자료

## 조사 보고서 형식

모든 보고서는 다음을 포함합니다:
- 3줄 요약
- 상세 내용 + 출처 URL
- 학습 포인트 3개
- 프로젝트 적용 방안
