# Sprint 143 C — UD Korean-GSD Silver Baseline 통합

> **결과**: 3번째 silver 데이터셋 통합. GSD는 KAIST와 달리 XPOS column에 Sejong 태그를 직접 사용 → 별도 변환기(identity mapping)만으로 통합. 도메인은 KLUE에 가장 가까운 현대 한국어 (Google news/web).

---

## 1. 데이터셋 발견

### 1.1 GSD vs KAIST XPOS scheme 차이

UD CoNLL-U는 column 5 (XPOS)를 언어별로 자유롭게 사용:

**KAIST** (Sprint 139에서 통합):
- 소문자 약어: `ncn`, `pvg`, `jca`, `ecs`, `mmd`...
- KAIST 자체 태그 체계 → Sejong 매핑 필요 (lossy)

**GSD** (이번 통합):
- 대문자 Sejong 태그 직접: `NNG`, `NNP`, `JKO`, `VV`, `VA`, `ETM`, `EF`, `EP`, `XSV`, `XSN`...
- mecab-ko-dic과 완전 호환 → **identity mapping** (변환 손실 없음)

### 1.2 변환 결과

| 파일 | 입력 | 변환 | Skip | 변환률 |
|------|------|------|------|--------|
| `ud_gsd_test.tsv` | 989 sentences | 971 | 18 | **98.2%** |
| `ud_gsd_dev.tsv` | 950 sentences | 933 | 17 | **98.2%** |
| 합계 | 1,939 | 1,904 | 35 | 98.2% |

Skip 사유: `NA` 태그 (~35건, 미분류 토큰).

**변환률 비교**:
- UD Kaist: 71.8% (KAIST → Sejong lossy)
- **UD GSD: 98.2%** (identity mapping, lossless)

## 2. Baseline 측정 (3 silver 비교)

### 2.1 단일 데이터셋 결과

| Metric | KLUE DP | UD Kaist | UD GSD |
|--------|---------|----------|--------|
| Sentences | 1,995 | 1,638 | 971 |
| Total eojeols | 22,404 | 19,241 | 11,246 |
| Morph strict | 66.8% | 66.3% | **67.4%** |
| Morph practical | 71.6% | 68.1% | 71.3% |
| Per-eojeol strict | 20.7% | 20.7% | **23.1%** |
| Per-eojeol practical | 23.5% | 21.8% | **25.8%** |
| Practical lift | +4.8pp / +2.8pp | +1.8pp / +1.1pp | +3.9pp / +2.7pp |

### 2.2 분석

**GSD는 KLUE에 가장 가까움**:
- morph strict GSD 67.4% (KLUE +0.6pp, Kaist +1.1pp)
- per-eojeol strict GSD 23.1% (KLUE +2.4pp, Kaist +2.4pp)
- **GSD가 KLUE보다 약간 높은 이유**: KLUE는 KLUE 자체 annotation 정책 (특정 convention 차이), GSD는 mecab-ko와 같은 형식이라 score 높음

**KAIST는 도메인 차이로 낮음**:
- KAIST는 역사/철학 텍스트 → XSN(적) 패턴 빈도 차이
- mecab의 NNG 분해 패턴이 학술 도메인에 부적합

**practical lift 차이**:
- KLUE +4.8pp morph: NNB/NNG/VA/VV/SP/SC 모두 흡수
- UD GSD +3.9pp morph: KLUE 유사 (대부분 흡수)
- UD KAIST +1.8pp morph: KAIST의 jcc(보격)/JKC가 mecab JKS와 충돌 → practical에 포함되지 않아 lift 작음

### 2.3 도메인 차이 정량화

각 silver 데이터셋이 보여주는 mecab 성능:
- **KLUE**: 현대 뉴스/리뷰 (Korean Editorial style)
- **UD Kaist**: 역사/철학/학술 (학술 텍스트)
- **UD GSD**: Google news/web (현대 informal-formal mix)

mecab strict morph 정확도는 66.3% (UD Kaist) ~ 67.4% (UD GSD) 사이 — 약 1.1pp 변동 폭.
도메인 변화는 작지만 패턴 분포는 매우 다름 (Sprint 140 KAIST vs KLUE 비교 결과 참조).

## 4. 핵심 학습 포인트

### 4.1 UD CoNLL-U는 데이터셋마다 XPOS scheme 다름

같은 UD format이지만 column 5 (XPOS)는 언어/데이터셋마다 자유롭게 정의. KAIST는 자체 태그, GSD는 Sejong 직접. **변환기는 데이터셋별 별도 작성**이 안전 (재사용 가정 깨질 수 있음).

### 4.2 도메인 다양성은 1pp 변동 폭

3 silver 데이터셋 morph strict 66.3~67.4% (1.1pp 변동). **단일 도메인 평가로는 1pp 안 보임** → 다중 silver 측정이 회귀 감지에 필요. Sprint 140 CI 4-gate 시스템의 가치 입증.

### 4.3 silver 변환률은 데이터셋 차이의 indicator

- UD GSD 98.2% (lossless identity)
- UD Kaist 71.8% (lossy KAIST→Sejong)
- 변환률 차이는 데이터셋의 mecab 호환성을 보여줌. GSD는 mecab과 같은 annotation 도구 사용 추측.
