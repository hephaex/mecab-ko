# KLUE Benchmark — License Attribution

The files in this directory are derived from the **KLUE Benchmark**.

## Source

- Repository: https://huggingface.co/datasets/klue/klue
- Config: `dp` (Dependency Parsing)
- Paper: Park et al., "KLUE: Korean Language Understanding Evaluation",
  NeurIPS 2021 Datasets & Benchmarks Track
- URL: https://klue-benchmark.com/

## Files

- `klue_dp_val.jsonl` — KLUE DP validation split (2,000 examples), full JSONL dump.
  Generated by `tools/dump_klue_dp_raw.py`.

## Use in mecab-ko

These data are used **only as evaluation input** for the mecab-ko Rust
morphological analyzer. They are not redistributed for training purposes.

The converted TSV form in `data/eval/klue_dp_val.tsv` carries the same
CC BY-SA 4.0 license.
