## CSV 형식

```
# 표면형,좌ID,우ID,비용,품사,분류,종류,활용형,조합읽기,원형,읽기,타입
국토교통부,0,0,-5000,NNP,중앙부처,*,*,국토교통부,국토교통부,국토교통부,*

```

### 비용(cost) 설정

모든 기관명에 `-5000` 고정 적용.

기관은 빈도와 무관하게 고유명사이며, mecab-ko 기본 사전의 NNP 평균 cost(+5230)보다 낮아 사용자 사전이 우선 적용됨.

## 갱신

이 사전은 **일회성**으로 생성되었습니다.

정부 조직 개편 시 수동 업데이트가 필요합니다:
1. 관보 코퍼스 meta.json에서 신규 기관 추출
2. 기본 사전/기존 사전 중복 검사
3. NNG 충돌 판정 (LLM 또는 수동)
4. CSV 업데이트

## 사용법

### Rust API

```rust
use mecab_ko::UserDictionary;

let mut dict = UserDictionary::new();
dict.load_csv("data/domain-dic/government/agencies.csv")?;
```

### CLI

```bash
mecab --user-dict data/domain-dic/government/agencies.csv \
  "국토교통부가 환경부와 협의했다"
```
